# XVoice

在任意应用的输入框里按下快捷键，对着麦克风说话，文字实时出现在光标处。用法类似 Windows 自带的 Win+H，识别用的是讯飞输入法的在线语音服务，支持方言。

纯 Go 实现，不使用 cgo。目前支持 Windows 10 / 11；Linux 和 macOS 的平台层还没有实现。

## 功能

- 对任意应用的输入框听写：浏览器、编辑器、聊天软件等。
- 边说边上屏，识别结果被修正时自动回改；也可以只在整句确定后上屏。
- 31 种语言和方言。
- 浮动语音条不抢焦点，出现在光标附近。
- 断线自动重连，重连期间录到的语音会补发。
- 单个可执行文件，约 6 MB，没有运行时依赖。

## 使用

1. 运行 `xvoice.exe`，程序驻留在托盘。
2. 点一下任意应用的输入框，按 `Ctrl + Alt + 空格` 开始说话。
3. 再按一次快捷键、按任意键，或者切换到别的输入框，听写立刻停止。

其他操作：

- **语音条**：点麦克风开始；听写中再点一次，会等最后一句识别完再结束。齿轮打开设置，叉号隐藏语音条。
- **托盘图标**：左键显示或隐藏语音条，右键菜单进入设置或退出。
- 大约 30 秒没有说话会自动停止。
- 程序只运行一个实例。再次运行（或带 `--settings` 参数运行）会打开设置窗口。
- 以管理员身份运行的程序收不到 XVoice 输入的文字，除非 XVoice 也以管理员身份运行。

## 设置

| 设置 | 说明 |
|---|---|
| 麦克风 | 设备拔掉后自动回退到系统默认麦克风 |
| 语言 | 普通话、英语，粤语和四川话等 24 种方言，藏语、维吾尔语、朝鲜语、日语、韩语 |
| 领域优化 | 购物、医疗、游戏、旅游，只对普通话有效 |
| 上屏方式 | 边说边上屏（修正时会退格重打），或整句确认后上屏（不回改） |
| 标点 | 智能添加、省略句末标点、省略所有标点、空格代替标点 |
| 自动结束 | 连续听写，或说完后停顿 1 到 5 秒自动结束 |
| 快捷键 | 点一下按钮，再按下想用的组合键 |
| 提示音 | 开始和结束时的提示音 |
| 开机启动 | 登录系统时自动运行 |

更改立即保存，从下一次听写开始生效。配置文件是用户配置目录下的 `xvoice/config.json`（Windows 上是 `%AppData%\xvoice\config.json`）。快捷键需要包含 Ctrl、Alt 或 Win（功能键 F1–F24 可以单独使用），主键可以是字母、数字、空格或功能键。

## 构建

需要 Go 1.24 或更新版本，不需要 C 编译器。

```powershell
./build.ps1
```

图标和 Windows 清单（控件样式、按显示器缩放）已经编译成 `cmd/xvoice/rsrc_windows_*.syso` 放在仓库里，普通构建不需要额外工具。更换 `assets/logo.svg` 之后重新生成：

```powershell
go generate ./cmd/xvoice
```

生成用到的 SVG 渲染库和 go-winres 只属于独立的 `tools` 模块，不会成为主程序的依赖。

## 代码结构

| 目录 | 内容 |
|---|---|
| `cmd/xvoice` | 入口，组装各模块 |
| `internal/asr` | 识别服务协议、语言表、断线重连 |
| `internal/audio` | 麦克风枚举与采集（Windows：WASAPI） |
| `internal/desktop` | 锁定外部输入框、全局快捷键、输入文字、开机启动（Windows：UI Automation、低级键盘钩子、SendInput） |
| `internal/session` | 一次听写的流程、上屏方式、标点处理，与平台无关 |
| `internal/ui` | 语音条、设置窗口、托盘（Windows：Win32 / GDI） |
| `internal/config` | 设置的读写 |
| `internal/winapi` | Windows COM 调用的公共部分 |
| `tools` | 独立模块：图标生成 |

平台相关的代码都在带 `_windows` 后缀的文件里，其他平台对应 `_other` 后缀的桩实现，所以整个项目在 Linux 和 macOS 上可以用 `CGO_ENABLED=0` 编译通过，只是还不能用。移植一个平台需要实现三处：`audio`（枚举和采集）、`desktop`（焦点输入框、快捷键、输入文字）、`ui`（窗口）。设置表单定义在平台无关的 `internal/ui/fields.go` 里，每个平台只写一个通用的渲染循环，增加设置项不需要改平台代码。

## 测试

```powershell
go test ./...
```

识别层的测试用本地的假服务端回放消息，不访问网络。要对真实服务做端到端测试，提供一段 16 kHz、单声道、16 位的 WAV：

```powershell
$env:TEST_WAV = 'speech.wav'
go test ./internal/asr -run TestLive -v
```

## 说明

- 这是非官方项目，与科大讯飞没有关系。识别依赖讯飞输入法 PC 客户端所用的在线服务，接口行为来自对该客户端的分析和实测，服务端调整后可能失效。
- 听写时，麦克风的声音会发送到该服务进行识别。
- 语言列表里的每一项都实测过确实会切换识别模型。官方客户端里的俄语、泰语、越南语、法语、德语、西班牙语、葡萄牙语、意大利语、阿拉伯语、彝语、壮语在这个接口上不生效，所以没有列出。方言的识别效果没有逐一验证。
